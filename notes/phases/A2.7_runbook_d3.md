# A2.7 Delivery 3: runbook (D118)

Delivery 3 runs the parser path on the headset: the acceptance (criteria 1, 2, 4, 6 and 7, headset halves) and the
deployed path's measurements. The headset code is Delivery 2's as corrected and accepted (D117, D118), with the artifacts
ChatGPT's review pinned: the APK `48d9f145`, the corrected parser folder `4ca6153a`, the Android `libse_llama.so`
`d1718b5b` and the model `86bc77bc`. Delivery 3 adds the laptop's helpers, the cross-session measurement summary and the
records; nothing in the app changes, so the APK you built is the one tested.

| Part | Machine | What | About |
|---|---|---|---|
| 1 | Laptop | Apply, records, the A2.7 and A2.5 suites, the reviewed artifacts verified, commit | 20 to 30 min |
| 2 | Laptop and headset | Install, push, identity (criterion 6), the Parser check, pull and judge (criteria 1, 2, 4 and 7) | 30 to 60 min |
| 3 | Headset worn, laptop recording | Three sessions from the panel's presets while frames and heat are recorded; pull, reports, summary | about 60 min |
| 4 | Laptop | The review archive | 5 min |

Save this file in the laptop's Downloads as `A2.7_runbook_d3.md`, beside `a27-d3.zip`. Everything else is where the
corrections left it: the corrected parser folder and its zip, the APK and the export's GGUF in `second-eyes-data`.

## Part 2 (LAPTOP and HEADSET): install, push, identity, the Parser check

Connect the headset by USB, awake and unlocked.


## Part 4 (LAPTOP): the review archive

```powershell
cd C:\Users\jubay\second-eyes; .\.venv\Scripts\Activate.ps1
. {
    $D = "C:\Users\jubay\second-eyes-data"; $RUN = (Get-Content "$D\a27-d3-run.txt").Trim(); $STAMP = (Get-Content "$D\a27-d3-results.txt").Trim()
    $R = "$D\$RUN-d3-review"; if (Test-Path $R) { throw "STOP: $R already exists" }
    New-Item -ItemType Directory $R -ErrorAction Stop | Out-Null
    Copy-Item "$D\a27-d3-tests-laptop.txt" $R -ErrorAction Stop
    Copy-Item -Recurse "$D\$RUN-identity" "$R\identity" -ErrorAction Stop
    Copy-Item -Recurse "runs\$RUN\raw\parser\$STAMP" "$R\parser-check-$STAMP" -ErrorAction Stop
    Copy-Item -Recurse "runs\$RUN\raw\parser-judged" "$R\parser-judged" -ErrorAction Stop

    python -c "import shutil, sys; print(shutil.make_archive(sys.argv[1], 'zip', sys.argv[1]))" $R
    if ($LASTEXITCODE -ne 0) { throw "STOP: the archive" }

    "{0:N1} MB" -f ((Get-Item "$R.zip").Length / 1MB)
```
