**What the new checks establish:**
- environments contributing none are exactly those whose retained parents sum to zero, split into no eligible parent
  and all quarantined, and never a contributing environment;
- `report` regenerates the counts and `pilot-spec.md` from a saved preparation, byte for byte equal to this code's own,
  records what it supersedes, and leaves the preparation untouched;
- `report` refuses a preparation whose files differ from its manifest, and an existing output folder.

**Not established here:**
- the regenerated report of the RTX PC's real preparation: Part 2 makes it;
- the static validator build on Windows: Part 3 builds it. In the pinned llama.cpp's `tests/CMakeLists.txt`, the
  target is defined when `NOT WIN32 OR NOT BUILD_SHARED_LIBS`.

**The deprecation warning.** A2.4's training code now uses the `dtype` keyword. `torch_dtype is deprecated` still
appears once each time an evaluation model loads: it comes from the accepted A2.3d loader
(`grounding/inference/iref_vla/model.py`), which fix 2 does not change. It is harmless.
