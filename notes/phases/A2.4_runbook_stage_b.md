# A2.4 Stage B: the runbook (nine fits, nine development evaluations)

**Package:** `a24-stageb.zip`, SHA-256 `0c9253b42a9a0f99e6c09bb3d9873c95bb378b3ee89e57de0b644e8f48db71f8`. It goes on top of `8aeb6ac` (A2.4 fix 3, as pushed). It holds only
the records of Stage A's closure (D113). This runbook replaces the earlier, unexecuted Stage B runbook. Its steps are
unchanged, checked against the current code.

**Save both files in the laptop's Downloads folder:** the zip, and this runbook as `A2.4_runbook_stage_b.md`. Part 0
copies the runbook into `notes\phases\` and commits it.

**What Stage B does** (D109; Stage A closed by D112 and D113):
- **B1:** seed 1 of the three configurations is fitted, then selected and merged; each merged model gets the accepted
  runner's smoke.
- **B2:** the continuation check, mechanical only.
- **B3:** seeds 2 and 3, fitted, selected and merged.
- **B4:** the nine development evaluations.
- **B5:** scoring and analysis. Targets are read only here.
- **B6:** the results archive.

It uses the frozen preparation `a24-20261012-032009\prep` and the accepted smoke.

**Rules:**
- **The order.** All nine selections finish (B1 and B3) before any development result is examined (B5).
- **Held-out evaluation stays closed.**
- **When to stop.** The blocks run without further approval while they succeed. Stop only for a material validity
  failure, leakage, a label problem, or an actual change of scope or budget.

**If a block stops.** Rerun the same block: a finished step is skipped, an interrupted fit or evaluation resumes under
its lock, and partial outputs are kept. Never rerun expensive inference to repair a table, a percentile convention or a
date.

- a `Traceback`: a defect. Send me the output.

## B1: seed 1 of the three configurations, selected and merged, then the runner smokes

```powershell
. {
  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $BASE = "C:\Users\jhossai3\second-eyes\grounding\models\qwen2.5-0.5b-instruct\hf"
  $P26 = "$DATA\iref-release\prep-20261010-211017"; $W26 = "$DATA\iref-release\work-20261010-211017"
  $TR = ".\.venv-train\Scripts\python.exe"; $EV = ".\.venv\Scripts\python.exe"
  $CFGS = @("direct.coordinates_v2", "direct.coordinates_relations_v2", "parser")
  foreach ($c in $CFGS) {
    $f = "$A24\fits\$c-s1"
    if (-not (Test-Path "$f\done.json")) {
      $extra = @(); if (Test-Path $f) { $extra = @("--resume") }
      & $TR -m grounding.a24 fit --prep "$A24\prep" --work "$A24\work" --config $c --seed-index 1 --base $BASE --out $f --device cuda @extra 2>&1 | Tee-Object -Append -FilePath "$A24\fits-s1.log"
      if ($LASTEXITCODE -ne 0) { throw "STOP: fit $c s1 (rerun this block to resume)" }
    }
    if (-not (Test-Path "$A24\merged\$c-s1\a24-identity.json")) {
      & $TR -m grounding.a24 merge --fit $f --prep "$A24\prep" --base $BASE --out "$A24\merged\$c-s1" --device cuda
      if ($LASTEXITCODE -ne 0) { throw "STOP: merge $c s1" }
    }
    if (-not (Test-Path "$A24\eval\$c-s1\smoke.json")) {
      & $EV -m grounding.a24 eval-direct --prep $P26 --work $W26 --preflight "$A24\preflight" --model "$A24\merged\$c-s1" --out "$A24\eval\$c-s1" --smoke-only --device cuda
      if ($LASTEXITCODE -ne 0) { throw "STOP: runner smoke $c s1" }
    }
  }
}
```

**Expect,** for each configuration:
- the fit: `"model_name": "a24.<configuration>.s1"`, with `"optimizer_steps"` equal to `"planned_optimizer_steps"`;
- the merge: its model name and identity, and `"check"` with `"passed": true`. `merge` applies the frozen selection rule
  itself and records it in the fit's `selection.json`;
- the runner smoke: `{"model_name": ..., "smoke_only": true}`. For the parser model this is a mechanical check of

## B4: the nine development evaluations

Each evaluation is one complete frozen evaluation of a selected checkpoint:
- a direct model runs all 10,860 requests;
- a parser model makes one decode per parent and resolves both views.

Nothing is scored here.

```powershell

  Set-Location "C:\Users\jhossai3\second-eyes"

  $EV = ".\.venv\Scripts\python.exe"

      }
    }
  } }
```

## B6: the results archive

```powershell
. {
  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $EV = ".\.venv\Scripts\python.exe"
  $R = "$A24-results"; if (Test-Path $R) { throw "STOP: $R already exists" }
  New-Item -ItemType Directory $R | Out-Null
  Copy-Item -Recurse "$A24\scores", "$A24\analysis" $R
  Copy-Item "$A24\continuation-s1.json", "$A24\*.log" $R
  foreach ($x in Get-ChildItem "$A24\fits" -Directory) {
    New-Item -ItemType Directory "$R\fits\$($x.Name)" -Force | Out-Null
    Copy-Item "$($x.FullName)\lock.json", "$($x.FullName)\done.json", "$($x.FullName)\log.jsonl", "$($x.FullName)\selection.json", "$($x.FullName)\merge-check.json" "$R\fits\$($x.Name)"
    Copy-Item -Recurse "$($x.FullName)\validation" "$R\fits\$($x.Name)" }
  foreach ($x in Get-ChildItem "$A24\merged" -Directory) { New-Item -ItemType Directory "$R\merged\$($x.Name)" -Force | Out-Null; Copy-Item "$($x.FullName)\a24-identity.json" "$R\merged\$($x.Name)" }
  foreach ($x in Get-ChildItem "$A24\eval" -Directory) {
    New-Item -ItemType Directory "$R\eval\$($x.Name)" -Force | Out-Null
    Copy-Item "$($x.FullName)\*.json" "$R\eval\$($x.Name)" -ErrorAction SilentlyContinue
    if (Test-Path "$($x.FullName)\run") { Copy-Item -Recurse "$($x.FullName)\run" "$R\eval\$($x.Name)" }
    Copy-Item "$($x.FullName)\results.jsonl" "$R\eval\$($x.Name)" -ErrorAction SilentlyContinue }
  & $EV -c "import shutil, sys; print(shutil.make_archive(sys.argv[1], 'zip', sys.argv[1]))" $R
  if ($LASTEXITCODE -ne 0) { throw "STOP: the archive" }
  (Get-FileHash "$R.zip" -Algorithm SHA256).Hash.ToLower()
  "{0:N1} MB" -f ((Get-Item "$R.zip").Length / 1MB)
}
```

**Expect:** the path of `a24-20261012-032009-results.zip`, its SHA-256 and its size. Python's `zipfile` writes
forward-slash paths, which unpack correctly everywhere.

The archive holds no weights or training data. Its ScanNet-derived text is for the project's own review only.
