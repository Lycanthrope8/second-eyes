# A2.4 runbook, Stage B (only after ChatGPT's Stage A review passes)

The nine planned fits, their selections and merges, then the nine development evaluations, scoring and analysis (D109).
No development result is examined before all nine fits are selected and merged.

**When the blocks may stop.** They run without further approval for routine success, and stop only for:
- a material validity failure;
- leakage;
- a label problem;
- an actual scope or budget change.

**Rerunning after an interruption.** Every block is safe to rerun: a finished step is skipped, an interrupted fit or
evaluation resumes, and partial outputs are kept. Never rerun expensive inference to repair a table, a percentile
convention or a date.

The times come from Stage A's `smoke-report.md` (an estimate).

Each block defines its own variables (the same in every block), so a block can be pasted alone.

## B1: seed 1 of the three configurations, selected and merged, then the runner smokes

```powershell
. {

  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $BASE = "C:\Users\jhossai3\second-eyes\grounding\models\qwen2.5-0.5b-instruct\hf"
  $P26 = "$DATA\iref-release\prep-20261010-211017"; $W26 = "$DATA\iref-release\work-20261010-211017"
  $TR = ".\.venv-train\Scripts\python.exe"; $EV = ".\.venv\Scripts\python.exe"
  $CFGS = @("direct.coordinates_v2", "direct.coordinates_relations_v2", "parser")
  foreach ($c in $CFGS) {
    $f = "$A24\fits\$c-s1"
    if (-not (Test-Path "$f\done.json")) {
      $extra = @(); if (Test-Path $f) { $extra = @("--resume") }
      & $TR -m grounding.a24 fit --prep "$A24\prep" --work "$A24\work" --config $c --seed-index 1 --base $BASE --out $f --device cuda @extra 2>&1 | Tee-Object -Append -FilePath "$A24\fits-s1.log"
      if ($LASTEXITCODE -ne 0) { throw "STOP: fit $c s1 (rerun this block to resume)" }
    }
    if (-not (Test-Path "$A24\merged\$c-s1\a24-identity.json")) {
      & $TR -m grounding.a24 merge --fit $f --prep "$A24\prep" --base $BASE --out "$A24\merged\$c-s1" --device cuda
      if ($LASTEXITCODE -ne 0) { throw "STOP: merge $c s1" }
    }
    if (-not (Test-Path "$A24\eval\$c-s1\smoke.json")) {
      & $EV -m grounding.a24 eval-direct --prep $P26 --work $W26 --preflight "$A24\preflight" --model "$A24\merged\$c-s1" --out "$A24\eval\$c-s1" --smoke-only --device cuda
      if ($LASTEXITCODE -ne 0) { throw "STOP: runner smoke $c s1" }
    }
  }
}
```

**Expected:**
- each fit prints its model name, with optimizer steps equal to the planned steps;
- each merge prints `"passed": true`;
- each runner smoke prints its model name.

## B4: the nine development evaluations

Each evaluation is one complete frozen evaluation of a selected checkpoint:
- a direct model runs all 10,860 requests;
- a parser model makes one decode per parent and resolves both views.

```powershell
. {

  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $BASE = "C:\Users\jhossai3\second-eyes\grounding\models\qwen2.5-0.5b-instruct\hf"
  $P26 = "$DATA\iref-release\prep-20261010-211017"; $W26 = "$DATA\iref-release\work-20261010-211017"
  $TR = ".\.venv-train\Scripts\python.exe"; $EV = ".\.venv\Scripts\python.exe"
  $CFGS = @("direct.coordinates_v2", "direct.coordinates_relations_v2", "parser")
  foreach ($s in 1, 2, 3) { foreach ($c in $CFGS) {
    $m = "$A24\merged\$c-s$s"; $o = "$A24\eval\$c-s$s"
    if ($c -eq "parser") {
      if (-not (Test-Path "$o-parser\manifest.json")) {
        $extra = @(); if (Test-Path "$o-parser") { $extra = @("--resume") }
        & $EV -m grounding.a24 eval-parser --prep $P26 --work $W26 --model $m --out "$o-parser" --device cuda @extra
        if ($LASTEXITCODE -ne 0) { throw "STOP: parser evaluation $c s$s (rerun to resume)" }
      }
    } else {
      if (-not (Test-Path "$o\run\manifest.json")) {

        & $EV -m grounding.a24 eval-direct --prep $P26 --work $W26 --preflight "$A24\preflight" --model $m --out $o --device cuda @extra
        if ($LASTEXITCODE -ne 0) { throw "STOP: direct evaluation $c s$s (rerun to resume)" }
      }
    }
  } }
}
```

**Expected:** six `eval\direct.*-s*\run\manifest.json` and three `eval\parser-s*-parser\manifest.json`.

## B5: scoring and analysis (targets read only here)

```powershell
. {

  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $BASE = "C:\Users\jhossai3\second-eyes\grounding\models\qwen2.5-0.5b-instruct\hf"
  $P26 = "$DATA\iref-release\prep-20261010-211017"; $W26 = "$DATA\iref-release\work-20261010-211017"
  $TR = ".\.venv-train\Scripts\python.exe"; $EV = ".\.venv\Scripts\python.exe"
  $CFGS = @("direct.coordinates_v2", "direct.coordinates_relations_v2", "parser")
  $loc = & $EV -m grounding.a24 locate --root "$DATA\a26c-20261011-013341" | Out-String | ConvertFrom-Json
  $r05 = @($loc.runs.'qwen2.5-0.5b-instruct'); $r7 = @($loc.runs.'qwen2.5-7b-instruct'); $rules = @($loc.rules)
  if ($r05.Count -ne 1 -or $r7.Count -ne 1 -or $rules.Count -ne 1) { $loc | ConvertTo-Json -Depth 4; throw "STOP: the A2.6c folders are not unique: choose them by hand" }
  $d = @(); foreach ($s in 1, 2, 3) { foreach ($c in $CFGS[0..1]) { $d += @("--direct", "$A24\eval\$c-s$s") } }
  $p = @(); foreach ($s in 1, 2, 3) { $p += @("--parser", "$A24\eval\parser-s$s-parser") }
  & $EV -m grounding.a24 score --prep $P26 --rules $rules[0] --base-run "qwen2.5-0.5b-instruct=$($r05[0])" --base-run "qwen2.5-7b-instruct=$($r7[0])" @d @p --out "$A24\scores"
  if ($LASTEXITCODE -ne 0) { throw "STOP: score" }
  & $EV -m grounding.a24 analyze --prep $P26 --scores "$A24\scores" --out "$A24\analysis"
  if ($LASTEXITCODE -ne 0) { throw "STOP: analyze" }
  Get-Content "$A24\analysis\report.md" -TotalCount 40
}
```

**Expected:** `report.md`, with the following sections:
- systems on their trained formats, plus labelled cross-format rows;
- seed means and spread;

- the supplementary breakdown;

## B6: the results archive

```powershell
. {

  Set-Location "C:\Users\jhossai3\second-eyes"
  $DATA = "C:\Users\jhossai3\second-eyes-data"; $A24 = (Get-Content "$DATA\a24-current.txt").Trim()
  $BASE = "C:\Users\jhossai3\second-eyes\grounding\models\qwen2.5-0.5b-instruct\hf"
  $P26 = "$DATA\iref-release\prep-20261010-211017"; $W26 = "$DATA\iref-release\work-20261010-211017"
  $TR = ".\.venv-train\Scripts\python.exe"; $EV = ".\.venv\Scripts\python.exe"
  $CFGS = @("direct.coordinates_v2", "direct.coordinates_relations_v2", "parser")
  $R = "$A24-results"; New-Item -ItemType Directory $R | Out-Null
  Copy-Item -Recurse "$A24\scores", "$A24\analysis" $R
  Copy-Item "$A24\continuation-s1.json", "$A24\*.log" $R
  foreach ($x in Get-ChildItem "$A24\fits" -Directory) {
    New-Item -ItemType Directory "$R\fits\$($x.Name)" -Force | Out-Null
    Copy-Item "$($x.FullName)\lock.json", "$($x.FullName)\done.json", "$($x.FullName)\log.jsonl", "$($x.FullName)\selection.json", "$($x.FullName)\merge-check.json" "$R\fits\$($x.Name)"
    Copy-Item -Recurse "$($x.FullName)\validation" "$R\fits\$($x.Name)" }
  foreach ($x in Get-ChildItem "$A24\merged" -Directory) { New-Item -ItemType Directory "$R\merged\$($x.Name)" -Force | Out-Null; Copy-Item "$($x.FullName)\a24-identity.json" "$R\merged\$($x.Name)" }
  foreach ($x in Get-ChildItem "$A24\eval" -Directory) {
    New-Item -ItemType Directory "$R\eval\$($x.Name)" -Force | Out-Null
    Copy-Item "$($x.FullName)\*.json" "$R\eval\$($x.Name)" -ErrorAction SilentlyContinue
    if (Test-Path "$($x.FullName)\run") { Copy-Item -Recurse "$($x.FullName)\run" "$R\eval\$($x.Name)" }
    Copy-Item "$($x.FullName)\results.jsonl" "$R\eval\$($x.Name)" -ErrorAction SilentlyContinue }
  Compress-Archive -Path "$R\*" -DestinationPath "$R.zip"
  Get-FileHash "$R.zip" -Algorithm SHA256
}
```

**Expected:** `<A24>-results.zip` and its SHA-256. It holds no weights or training data. Its ScanNet-derived text is
for the project's own review only.

**Then:** the closing records, a separate step after the review of the results.
