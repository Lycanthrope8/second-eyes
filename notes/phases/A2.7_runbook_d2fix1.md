## Part 3 (LAPTOP): the build evidence and the review archive

```powershell
cd C:\Users\jubay\second-eyes; .\.venv\Scripts\Activate.ps1
. {
    $D = "C:\Users\jubay\second-eyes-data"; $E = "$D\a27-d2fix1-evidence"; $APK = "$D\a27-d2fix1-app.apk"
    $LOG = "$env:LOCALAPPDATA\Unity\Editor\Editor.log"
    foreach ($p in $E, $APK, $LOG) { if (-not (Test-Path $p)) { throw "STOP: $p is missing" } }
    Copy-Item $LOG "$E\unity-editor.log" -ErrorAction Stop
    $built = Select-String -Path $LOG -Pattern "Build completed with a result of '(\w+)'" | Select-Object -Last 1
    $cs = (Select-String -Path $LOG -Pattern "error CS\d{4}").Count
    @("unity: " + $(if ($built) { $built.Line.Trim() } else { "no build result in the log" }),
      "compiler error lines in the log: $cs",
      "apk: " + (Get-FileHash $APK -Algorithm SHA256).Hash.ToLower() + ", " + (Get-Item $APK).Length + " bytes") | Tee-Object -FilePath "$E\unity-build.txt"
    if (-not $built -or $built.Line -notmatch "'Succeeded'") { throw "STOP: the log shows no successful build (see $E\unity-build.txt)" }
    git diff --output="$E\projectsettings-after-build.diff" -- quest-app/ProjectSettings/ProjectSettings.asset
    Copy-Item "native\out\host\build.json" "$E\native-host-build.json" -ErrorAction Stop
    Copy-Item "native\out\android-arm64\build.json" "$E\native-android-arm64-build.json" -ErrorAction Stop
    Copy-Item "$D\a27-20261013-200925-parser-d117\manifest.json" "$E\parser-d117-manifest.json" -ErrorAction Stop
    Copy-Item "$D\a27-20261013-200925-port-d117\summary.json" "$E\port-d117-summary.json" -ErrorAction Stop
    python -c "import shutil, sys; print(shutil.make_archive(sys.argv[1], 'zip', sys.argv[1]))" $E
    if ($LASTEXITCODE -ne 0) { throw "STOP: the archive" }
    (Get-FileHash "$E.zip" -Algorithm SHA256).Hash.ToLower()
    "{0:N1} MB" -f ((Get-Item "$E.zip").Length / 1MB)
}
```

**Expect:** the Unity line (`Build completed with a result of 'Succeeded' ...`), the count of compiler-error lines (from
the whole editor session, so earlier imports count too; the review reads the log), the APK's hash and size, then the
archive's hash and size.
