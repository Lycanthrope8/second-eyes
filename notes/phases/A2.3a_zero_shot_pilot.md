# A2.3a · Zero-shot direct-selection pilot

Date: 6 October 2026 · Decision: D81 · Brief: ChatGPT's A2.3a implementation brief (5 October 2026) · Baseline: `c5b7704`
with A2.2d staged on top (not yet committed); the sandbox's copy of that baseline was verified against the public
repository on 5 October.

Status: implemented and tested with labelled fakes and the pinned tokenizer. The accepted request preparation, the
real-model canary and the 128-request pilot run on the project lead's machine; their run IDs and numbers are pending.

## 5. Decisions taken

D81. The brief expected D79, but D79 and D80 are allocated to A1.10a (`notes/phases/A1.10_detector.md`) and enter
`notes/decisions.md` with its commit, so this is D81.

Implementation readings, recorded here: a request over the context limit is `context_budget_exceeded` even when its
scene is empty (the brief's rule applies to every prepared request); the canary's independent path reads the model's
last hidden state through its own `lm_head`; checkpoint identity is accepted from Hugging Face's local-folder download
metadata (commit and ETag per file) or an operator-supplied published SHA-256 of the weights, and refused otherwise;
deterministic algorithms are requested in warn-only mode with a cuBLAS workspace setting, and any warning is recorded;
the run requires the model description the requests were prepared with.
