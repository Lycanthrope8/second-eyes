copies the runbook into `notes\phases\` and commits it.

**What fix 2 changes:**
- **The count.** An environment contributes none only when its retained parents sum to zero. It is shown in one of two
  groups: no parent eligible under A2.6b, or eligible parents all quarantined. The first `pilot-spec.md` instead
  listed every environment with any stratum lacking a retained parent. The cohorts, labels and training data were
  correct.
- **`report`.** It regenerates the counts and `pilot-spec.md` from the saved preparation into
  `a24-20261012-032009\prep-report`. It reruns nothing, keeps the original, and records what it supersedes.
- **The `dtype` keyword.** A2.4's training code uses transformers' `dtype` keyword: the same behaviour, without the
  deprecation warning.
- **Part 3 (the grammar check).** It builds llama.cpp's validator statically. In the pinned llama.cpp the target
  exists on Windows only with `BUILD_SHARED_LIBS=OFF`.

## Part 3 (LAPTOP): the grammar against the pinned llama.cpp (skip if you already have `a24-gbnf.zip`)

First copy `a24-20261012-032009\prep\reference_only\label-strings.jsonl` from the RTX PC to the laptop's Downloads
folder. Then open **Developer PowerShell for VS 2022**:

```powershell
cd C:\Users\jubay\second-eyes
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force; .\.venv\Scripts\Activate.ps1
. {
    $L = "third_party\llama.cpp"
    if ((git -C $L rev-parse HEAD).Trim() -ne "eae11d2217fe9225d1aaba48773b6cca45ae4de9") { throw "STOP: third_party\llama.cpp is not b11277" }
    if (-not (Test-Path "$HOME\Downloads\label-strings.jsonl")) { throw "STOP: copy label-strings.jsonl from the RTX PC (a24-20261012-032009\prep\reference_only) to Downloads first" }
    $B = "$L\build-gbnf-static"
    if (-not (Get-ChildItem $B -Recurse -Filter test-gbnf-validator.exe -ErrorAction SilentlyContinue)) {
        cmake -S $L -B $B -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF -DLLAMA_BUILD_TESTS=ON -DLLAMA_BUILD_EXAMPLES=OFF -DLLAMA_BUILD_SERVER=OFF -DLLAMA_CURL=OFF -DGGML_NATIVE=OFF
        if ($LASTEXITCODE -ne 0) { throw "STOP: cmake configure" }
        cmake --build $B --target test-gbnf-validator
        if ($LASTEXITCODE -ne 0) { throw "STOP: the validator build" }
    }
    $X = (Get-ChildItem $B -Recurse -Filter test-gbnf-validator.exe | Select-Object -First 1).FullName
    $V = "$HOME\Downloads\a24-gbnf-tests.txt"
    python grounding\tests\test_a24_language.py --samples "C:\Users\jubay\second-eyes-data\iref-release-samples" --gbnf-validator $X *>&1 | Tee-Object -FilePath $V
    if (Select-String -Path $V -Pattern "^\s*FAIL\s|Traceback|passed, [1-9]\d* failed" -CaseSensitive -Quiet) { throw "STOP: a test failed (see $V)" }
    $G = "C:\Users\jubay\second-eyes-data\a24-gbnf-$(Get-Date -Format yyyyMMdd-HHmmss)"
    python -m grounding.a24 gbnf-check --validator $X --out $G --labels-file "$HOME\Downloads\label-strings.jsonl"
    if ($LASTEXITCODE -ne 0) { throw "STOP: the grammar check" }
    $s = Get-Content "$G\summary.json" -Raw | ConvertFrom-Json
    if ($s.disagreements -ne 0 -or $s.unreadable_verdicts -ne 0) { throw "STOP: llama.cpp and the Python grammar disagree (see $G\verdicts.jsonl)" }
    Copy-Item $V, "$HOME\Downloads\a24-tests-laptop.txt" $G
    Compress-Archive -Path $G -DestinationPath "$HOME\Downloads\a24-gbnf.zip" -Force
    (Get-FileHash "$HOME\Downloads\a24-gbnf.zip" -Algorithm SHA256).Hash.ToLower()
}
```

```powershell
. {
    $A = (Get-Content "$D\a24-current.txt").Trim()
    if (-not (Test-Path "$A\a24-gbnf.zip")) { throw "STOP: copy a24-gbnf.zip from the laptop into $A first" }

    $R = "$A-review"; if (Test-Path $R) { throw "STOP: $R already exists" }
    Expand-Archive "$A\a24-gbnf.zip" -DestinationPath "$A\gbnf" -Force
    New-Item -ItemType Directory $R | Out-Null
    Copy-Item "$A\spec", "$A\preflight", "$A\runner-smoke", "$A\gbnf", "$A\prep-report" $R -Recurse
    New-Item -ItemType Directory "$R\prep" | Out-Null
    Get-ChildItem "$A\prep" | Where-Object { $_.Name -ne "training_data" } | ForEach-Object { Copy-Item $_.FullName "$R\prep" -Recurse }
    New-Item -ItemType Directory "$R\smoke" | Out-Null
    Copy-Item "$A\smoke\smoke.json", "$A\smoke\smoke-report.md" "$R\smoke"
    foreach ($c in Get-ChildItem "$A\smoke" -Directory) {
        $d = "$R\smoke\$($c.Name)"; New-Item -ItemType Directory $d | Out-Null
        foreach ($f in "fit\lock.json", "fit\log.jsonl", "fit\done.json", "fit\selection.json", "fit\merge-check.json", "merged\a24-identity.json") {
            if (Test-Path "$($c.FullName)\$f") { Copy-Item "$($c.FullName)\$f" "$d\$($f -replace '\\', '-')" } }
        if (Test-Path "$($c.FullName)\fit\validation") { Copy-Item "$($c.FullName)\fit\validation" "$d\validation" -Recurse } }
    Copy-Item "$A\*.log", "$A\pip-freeze-*.txt" $R
    foreach ($f in "a24-tests-rtx.txt", "a24-fix1-tests-rtx.txt", "a24-fix2-tests-rtx.txt") { if (Test-Path "$D\$f") { Copy-Item "$D\$f" $R } }
    Compress-Archive -Path "$R\*" -DestinationPath "$R.zip"
    (Get-FileHash "$R.zip" -Algorithm SHA256).Hash.ToLower()
    "{0:N1} MB" -f ((Get-Item "$R.zip").Length / 1MB)
}
```
