# Entries for the Second Eyes decision log (Quest-only path)

For `notes/decisions.md`. The pushed log ended at D130 and O29 (19 October). Rows follow the log's columns; decisions go
newest first and open items in the Open table. `python scripts/update_decision_log.py` inserts the rows whose IDs the log
doesn't have yet, and leaves any existing row alone.

Reconstructed on 18 November from the session records. Where a record is missing, the entry says so rather than filling
the gap. Commit hashes marked † come from Claude's session summaries and were not checked against git
(`git log --oneline` confirms them). Status words: *confirmed result*, *failed check*, *provisional measurement*,
*pending*.
